# Evening Daily Report Routine

このスキルは、1日の業務終了時に作業ログと日報を自動生成するための手順書です。

## 実行手順

1. **実績の回収**:
   - `TODO.md` の「本日完了したタスク」およびチェックが入った項目を読み取る。
   - 当日のGitコミットログ（関連リポジトリ）を確認する。

2. **日報の作成**:
   - `daily/template-daily.md` のフォーマットに従い、当日日付のファイル（例: `daily/2026-11/2026-11-08.md`）を作成する。
   - 完了したタスク、レビュー実績、直面した課題・解決策を記述する。

3. **TODO.md のリセットと明日への繰り越し**:
   - 完了したタスクを「本日完了したタスク」にアーカイブする。
   - 未完了のタスクのうち、明日に持ち越すものを「今日の最優先タスク」「通常タスク」として再編成する。

4. **ユーザーへの報告**:
   - 作成した日報の要約と、明日の持ち越しタスクをチャットに提示する。
