# タスク優先度判定ルール (Task Priority Rules)

AIは、外部ソース（Outlook, Teams, Bitbucket）からタスクを抽出・整理する際、以下の基準に従って優先度を分類してください。

## 1. 優先度高 (High Priority / 今日必ず対応)
- **基板・量産トラブル**: 試作・量産ライン停止や部品調達のクリティカルな変更通知。
- **ブロッキングPR**: 自分が承認しないと後続の開発・テストが進まないPull Request。
- **重要度Highのメール**: 件名に【至急】【緊急】が付いたメール、または社外ベンダーからの重要納期連絡。
- **当日締切の社内業務**: 当日提出期限の書類や承認事項。

## 2. 優先度中 (Medium Priority / 通常のエンジニアリング業務)
- **直接メンション**: Teamsで自分個人に対して回答を求められている連絡。
- **担当開発タスク**: 製品A/製品Bの回路設計、ファームウェア実装、テスト。
- **一般PRレビュー**: 急ぎではないがオープンになっているPRの確認。

## 3. 優先度低 (Low Priority / 隙間時間または情報共有)
- **チャンネル全体へのアナウンス**: Teamsの全社・部門連絡。
- **CCに入っているだけのメール**: 情報共有目的のメール。
- **長期的な調査・検討タスク**: 納期に余裕のある技術調査。
